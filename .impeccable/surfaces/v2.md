## Direction contract

THESIS: This site proves rather than claims. Every fact ships stamped Verified or honestly marked Open,
refusing the generic "three feature cards plus a stat row" junior-portfolio default that asserts skill
instead of showing it measured.

OWN-WORLD: Cool bone-paper ground (#EDEAE2), near-black proof ink (#17181A), one saturated proof-red
(#D6291A) reserved only for stamps, correction marks, and status words. IBM Plex Mono for labels, data,
and proof-marks; a period-appropriate oldstyle serif (final face logged in DESIGN.md at finish) for
specimen-scale display headings only, never body text. Corner registration crosses as a recurring,
functional section-boundary marker, never pure decoration. Strict baseline/character grid; theme and
project-switch state changes cut instantly, no eased transition.

STORY: A recruiter understands within one viewport that this person's claims are checked, not asserted.
They read Filip's name and role set at specimen scale, see each project carrying an explicit stamped
state (Shipped / In Progress), and can open a project into full case-study detail without leaving the
proof-sheet grammar.

FIRST VIEWPORT: Full-bleed proof sheet. Top band: name and role set at graduated specimen sizes (largest
type on the page), a small "fd." wordmark with a red proof-dot top-left (a plainer mark than a
registration-cross monogram, kept after three cross-based logomark options were tried and rejected).
Below: a one-line proof-stamp status reading the real internship status. Below that: the work list as
stamped rows (title, one-line thesis, stamped state word). Primary action: into the first case study.
Secondary: contact, placed level with it, never competing in size.

FORM: The Proof Sheet (printing-house type specimen and press-proof sheets), position 6 of 7 in the
resonance-ordered candidate list, assigned by the roll rather than chosen for ranking top; seed key
bb5ba904.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
DESIGN.md, and every shipping raster carrying its provenance.
